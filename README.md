**Currency Exchange System:**

A simple Python-based command-line Currency Exchange System that allows users to view exchange rates and convert between multiple currencies using a menu-driven interface.

**✨ Features:**
- View exchange rates of multiple currencies
- Convert currency between different currencies
- Continuous menu-driven system
- Input validation for safe user experience
- Accurate conversion using base logic (USD)
- Technologies Used
- Python
- Basic Programming Concepts
- CLI (Command Line Interface)

**Project Structure:**

currency-exchange-system/
│__ .venv
├── main.py
└── README.md

**How to Run**

**Clone Repository:**
git clone https://github.com/Ms-Noor409/Currency_Exchange_System.git

**Go to Project Folder:**
cd currency-exchange-system

**Run Program:**
python main.py

**How It Works:**

User selects option from menu
System shows available currencies and rates
User enters source and target currency
System converts amount using exchange logic
Result is displayed in terminal

**Example:**

===== Currency Exchange System =====
1. View Exchange Rates
2. Convert Currency
3. Exit
